# ZELÓN — Online Bag Shop

## Project Overview

ZELÓN is an online bag shop developed as a course project using HTML, CSS, PHP, and MySQL. The project combines a customer-facing website with a product management dashboard, allowing users to explore the brand and manage product information through a database-connected system.

The design follows an elegant fashion-oriented visual identity, combining burgundy, beige, black, and white with product imagery, modern typography, and structured layouts.

## Project Goal

The goal was to develop an online shopping website that combines an organized product presentation with practical backend functionality. The project provided experience connecting frontend interfaces with PHP and MySQL to implement authentication, database operations, and product management.

## Key Features

### Website Interface
- Landing page with promotional content and navigation.
- Product section presenting different types of bags.
- About Us and Contact sections.
- Consistent visual identity and responsive-style layouts.

### Authentication
- Login and registration forms.
- PHP session-based authentication.
- Input validation with warning messages for incomplete or incorrect information.
- Logout functionality.

### Product Management
- Dashboard for managing product information.
- Product registration with details such as name, material, category, price, quantity, availability, and description.
- Product listing in a structured table.
- CRUD operations: create, read, update, and delete products.
- Product editing and deletion.
- Product reports displaying stored information.

## Design & Development

The interface uses a burgundy, beige, black, and white colour palette, complemented by product photography, modern typography, custom styling, and card-based layouts.

The development combines:
- **HTML5** for page structure and content.
- **CSS3** for layouts, styling, and visual presentation.
- **PHP** for authentication, sessions, form processing, and backend functionality.
- **MySQL** for storing and managing application data.
- **JavaScript** for interactive elements.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/luljeta-hoti/zelon.git
   ```

2. Set up a local PHP and MySQL environment.
3. Import `zelon_shop.sql` into your MySQL database.
4. Check the database connection settings in the PHP files and adjust them to match your local environment.
5. Run the project using your local PHP development server.
6. Open `Landingpage.html` in your browser to explore the website.
